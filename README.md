# Rupis

**Rupis**是一门专门为描述《我的世界》Java版本红石结构的脚本语言，它能让你在制作红石机器时不再费力的一个一个搭方块，让你的红石机器被简单，快速的描述。
这个仓库里存下了Rupis解释器和Rupis ide的所有源代码。

**特别注意：目前的Rupis和它的自述文件并不是正式版本，请谨慎使用**
